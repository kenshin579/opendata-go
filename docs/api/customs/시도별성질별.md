# 시도별 성질별 수출입실적 (getSidotempertradeList)

> `GET https://apis.data.go.kr/1220000/sidotempertrade/getSidotempertradeList`

한 시도의 성질별 수출 또는 수입 란수·금액을 **연 단위 합산**으로 조회한다. 성질 분류는 [성질별](성질별.md)과 같은 5자리 현행 분류다. 포털: [15101639](https://www.data.go.kr/data/15101639/openapi.do)

API 13~17 은 API 1~12 와 응답 필드 이름·숫자 형식·금액 단위가 다르다. 대응 관계는 [관세청 README 응답 필드 계열](README.md#응답-필드-계열)을 본다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| dtlTmprYn | 세부성질여부 | - | N | `Y` 면 세분류(5자리 말단)까지 포함(경기도 수출 6개월 175행). 생략하면 대·중분류만(22행). 행 수는 총계 포함 |
| sidoCd | 시도코드 | - | Y | 2자리(`41` 경기도). 코드는 [codes/시도코드.csv](codes/시도코드.csv) — 광주·전남은 2026.7.1. 전후로 코드가 다르다([코드표 함정](README.md#코드표-함정)) |
| imexTpcd | 수출입구분코드 | - | Y | `1` 수출, `2` 수입([codes/수출수입코드.csv](codes/수출수입코드.csv)) |
| imexTmprClsfCd | 수출입성질분류코드 | - | N | 5자리 문자열(`11101`, `4Z000`). [codes/성질분류코드.csv](codes/성질분류코드.csv) — 수출·수입 표가 다르다. 미실측. 생략하면 전 성질 |

## 응답 필드 (`response/body/items/item`)

숫자 필드는 모두 **공백 패딩 + 천 단위 콤마 문자열**(`       2,354,891`, 16자 고정폭)이다. 명세의 명칭은 "수출…" 이지만 `imexTpcd=2` 면 같은 필드에 수입 값이 온다.

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| priodTitle | 기간 | | **연도 `2026`**(월이 아님). 총계 행은 `총계`. 명세 타입은 number |
| tmprTpcd | 성질코드 | | 5자리 문자열(`10000`, `4Z000`). 총계 행은 `00000` |
| cdValtValNm | 성질명 | | `1. 식료 및 직접소비재`, `가. 섬유원료`, `- 돼지고기`. **총계 행에는 태그가 없다** |
| imexLnCnt | 수출입 란수 | 건 | 명세는 "수출품목건수" |
| imexUsdAmt | 수출입금액 | 천 달러 | 명세는 "수출금액(달러)" |

## 샘플

```
GET https://apis.data.go.kr/1220000/sidotempertrade/getSidotempertradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&sidoCd=41&imexTpcd=1
```

22행(총계 + 대분류 4 + 중분류 17). 첫 행이 총계다.

```xml
<item><imexLnCnt>       2,354,891</imexLnCnt><imexUsdAmt>     159,022,310</imexUsdAmt><priodTitle>총계</priodTitle><tmprTpcd>00000</tmprTpcd></item>
<item><cdValtValNm>1. 식료 및 직접소비재</cdValtValNm><imexLnCnt>         127,941</imexLnCnt><imexUsdAmt>         796,523</imexUsdAmt><priodTitle>2026</priodTitle><tmprTpcd>10000</tmprTpcd></item>
<item><cdValtValNm>바. 기 타</cdValtValNm><imexLnCnt>         276,735</imexLnCnt><imexUsdAmt>       3,065,264</imexUsdAmt><priodTitle>2026</priodTitle><tmprTpcd>4Z000</tmprTpcd></item>
```

## 함정

- **계층이 섞여 온다. 전부 더하면 중복 합산이다.** 기본은 대분류(`10000`)와 중분류(`31000`, `4Z000`)가 함께 오고, `dtlTmprYn=Y` 는 여기에 세분류(`11101`, `4Z001`)까지 더해 175행이다(총계 포함). 대분류 4행의 합이 총계와 맞는다(천 단위 반올림 차). [성질별](성질별.md)이 말단만 주는 것과 반대다.
- 대분류 `1.`·`2.` 는 중분류 행이 없다. 기본 응답에서 1·2 는 대분류 한 행뿐이고, `Y` 에서는 바로 세분류(`11101`)가 붙는다.
- **총계 행은 `tmprTpcd` 가 `00000` 이고 `cdValtValNm` 태그가 없다**([총계 행](README.md#총계-행)).
- **연 단위 합산·천 달러**다([시도별](시도별.md#함정)). 총계는 [시도별품목별](시도별품목별.md) 경기도 총계와 란수·금액이 같다.
- **성질코드는 문자열이다**(`4Z000`, `3A000`). 같은 코드가 수출·수입에서 뜻이 다르다(`10000` 수출 `1. 식료 및 직접소비재`, 수입 `1. 소비재`). 수입(`imexTpcd=2`)은 같은 필드로 21행(총계 포함).
- 명세의 `sidoCd` 타입은 number 지만 다른 API 와 같이 2자리 문자열로 보내면 된다.
