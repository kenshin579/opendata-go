# 세관별 수출입실적 (getCustomstradeList)

> `GET https://apis.data.go.kr/1220000/customstrade/getCustomstradeList`

세관(통관지)별로 월별 수출입 건수·금액·무역수지를 조회한다. 본부세관 단위 또는 개별 세관 단위로 받을 수 있다. 포털: [15101633](https://www.data.go.kr/data/15101633/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| cstmSgnYn | 세관구분여부 | - | N | `Y` 본부세관 단위(월 7행), `N` 개별 세관 단위(월 45행). **생략하면 `Y`** 와 같다. [codes/세관구분코드.csv](codes/세관구분코드.csv) |

## 함정

- **`cstmSgnYn` 은 이름과 반대로 읽힌다.** "세관 구분 여부 = Y" 라 세관별로 나눌 것 같지만 `Y`(와 생략)는 **본부 단위**로 묶고, `N` 이 **개별 세관**으로 나눈다. 코드표의 `Y 본부세관`, `N 세관` 과는 맞는다. 생략과 `Y` 의 응답은 바이트까지 같다.
- 본부 단위(`Y`)에서는 `cstm`·`statCdCntnKor` 가 빈 태그가 아니라 `-` 로 온다.
- 두 모드의 합계는 같다(6개월 수출 496,114,738,264달러 = [종류별](종류별.md) 총계). 총계 행은 없으니 직접 더한다.
- `center` 값이 코드표와 다르다. 코드표는 `서울세관`·`인천공항세관`·`평택세관` 처럼 적었지만 응답은 `서울본부`·`인천공항본부`·`직할세관`(평택 소속) 이다.
- **세관코드는 0 으로 시작한다**(`010`, `070`). 문자열로 다룬다([코드표 함정](README.md#코드표-함정)).
- **기간이 `202601` 형식이다**([응답 필드 계열](README.md#응답-필드-계열)).
