# 성질별 국가별 수출입실적 (getNtempertradeList)

> `GET https://apis.data.go.kr/1220000/ntempertrade/getNtempertradeList`

관세청 **현행 성질별 분류**(5자리)로 한 국가의 월별 수출 또는 수입 중량·금액을 조회한다. [성질별](성질별.md)에 국가 조건을 더한 것이다. 포털: [15100476](https://www.data.go.kr/data/15100476/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | 100 | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | 6 | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | 6 | Y | `YYYYMM` |
| imexTpcd | 수출입구분코드 | 1 | Y | `1` 수출, `2` 수입([codes/수출수입코드.csv](codes/수출수입코드.csv)) |
| imexTmprClsfCd | 수출입성질분류코드 | 5 | N | 5자리 문자열(`11201`). 수출·수입 코드표가 다르다([codes/성질분류코드.csv](codes/성질분류코드.csv)). 생략하면 전 성질 |
| cntyCd | 국가코드 | 2 | Y | 대문자 2자리(`US`). 코드는 [codes/국가코드.csv](codes/국가코드.csv) |

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | `2026.01` 형식 |
| impexp | 수출입구분 | | `수출` 또는 `수입` |
| statCd | 국가코드 | | `US` |
| statCdCntnKor1 | 국가명 | | `미국` |

| wgt | 중량 | kg | 정수 |
| dlr | 금액 | 달러 | 정수 |

## 샘플

```
GET https://apis.data.go.kr/1220000/ntempertrade/getNtempertradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&imexTpcd=1&cntyCd=US
```

## 함정

- 성질코드의 형식·말단 코드만 오는 점·코드표에 없는 `32701`·`32801` 은 [성질별](성질별.md#함정)과 같다(이 fixture 에서도 확인).
- 그 국가에 실적이 없는 성질은 행이 빠진다(미국 수출 2026.01 은 141개, 전체 [성질별](성질별.md)은 152개).
- `cntyCd` 생략 시 동작은 실측하지 않았다(명세는 필수). 국가코드는 대문자만 받는다([국가별](국가별.md#함정)).
