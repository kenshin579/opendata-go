# 성질별 수출입실적 (getIdfytempertradeList)

> `GET https://apis.data.go.kr/1220000/Idfytempertrade/getIdfytempertradeList`

관세청 **현행 성질별 분류**(5자리, 수출·수입 코드표가 따로 있음)로 월별 수출 또는 수입 중량·금액을 조회한다(국가 구분 없음). 수출·수입 공통 8자리 분류로 보려면 [신성질별](신성질별.md)을 쓴다. 포털: [15102109](https://www.data.go.kr/data/15102109/openapi.do)

서비스 경로는 대문자 `I` 로 시작하는 `Idfytempertrade` 다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |

| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 함정

- **명세의 `statCd`·`statCdCntnKor1` 은 응답에 없다.** 이 API 는 국가 구분이 없다. 국가별로 보려면 [성질별국가별](성질별국가별.md).
- **성질코드는 문자열이다.** 명세는 number 지만 `4Z001`, `26A01`, `3A101` 같은 값이 온다.
- **말단 코드만 온다.** 코드표의 상위 코드(`10000` `1. 식료 및 직접소비재`, `11300` `- 어패류와 조제품` 처럼 `00` 으로 끝나는 것)는 응답 행으로 나오지 않는다. 상위 합계는 직접 더한다.
- **같은 코드가 수출·수입에서 뜻이 다르다.** `11101` 은 수출 `- 돼지고기`, 수입 `- 소맥`. `imexTpcd=2` 는 6개월 1,079행([코드표 함정](README.md#코드표-함정)).
- **응답에 코드표에 없는 코드가 있다.** 수출 `32701` `- 면사`, `32801` `- 면직물` 은 `성질분류코드.csv` 에 없다. 이름은 응답 값을 쓴다.
- 그 달 실적이 없는 성질은 행이 빠져 월마다 행 수가 다르다.
- `imexTpcd` 누락은 99 `필수 요청변수가 누락되었습니다.`(`<body/>`).
