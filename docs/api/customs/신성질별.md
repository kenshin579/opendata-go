# 신성질별 수출입실적 (getNewtempertradeList)

> `GET https://apis.data.go.kr/1220000/newtempertrade/getNewtempertradeList`

관세청 **신성질별 분류**(수출·수입 공통 8자리, 대·중·소·세·세세분류)로 국가별 월별 수출 또는 수입 중량·금액을 조회한다. [성질별](성질별.md)의 현행 분류(5자리, 수출·수입 코드표가 다름)와는 다른 코드 체계다. 포털: [15101616](https://www.data.go.kr/data/15101616/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| imexTpcd | 수출입구분코드 | - | Y | `1` 수출, `2` 수입([codes/수출수입코드.csv](codes/수출수입코드.csv)) |

## 함정

- **응답이 매우 크다.** 페이지네이션이 없어([공통 규약](../README.md#공통-인자)) 수출 1개월이 23,650행·5.1MB, 6개월이 30.5MB 다. 성질코드로 좁히면 `13050102` 6개월 1,010행, 12개월 2,003행. 한 국가만 필요하면 [신성질별국가별](신성질별국가별.md)을 쓴다.
- **성질통합분류코드는 8자리 세세분류만 매칭된다.** 코드표는 HS10 → 신성질 대·중·소·세·세세분류 매핑 표라 코드 열이 여럿인데, 인자에는 15번째 열(세세분류)을 넣는다. 상위 코드(`13050000` 등)는 에러 없이 0건이다(신성질별국가별에서 실측, [코드표 함정](README.md#코드표-함정)). 코드표의 세세분류는 758개, 이 응답에 나온 것은 707개로 모두 코드표에 있다.
- **말단(세세분류) 행만 온다.** 대·중분류 합계가 필요하면 코드표의 상위 코드 열로 묶어 직접 더한다.
- 명세의 `godsCd` 타입은 number 지만 문자열로 다룬다(8자리 코드).
- 국가명의 `&` 는 `&amp;` 로 이스케이프된다(`투르크 &amp; 카이코스 군도`, [정상 응답](../README.md#정상-응답)).
