# 경제권별 수출입실적 (getEconomytradeList)

> `GET https://apis.data.go.kr/1220000/economytrade/getEconomytradeList`

EU·OECD·ASEAN 같은 경제권별 월별 수출입 건수·금액·무역수지를 조회한다. 포털: [15101632](https://www.data.go.kr/data/15101632/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| cntnEbkUnfcClsfCd | 대륙경제권통합분류코드 | - | N | 경제권코드 2자리(`10` EU). 생략하면 전 경제권. 코드는 [codes/경제권코드.csv](codes/경제권코드.csv) |

## 응답 필드 (`response/body/items/item`)

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | `2026.01` 형식 |
| statCd | 경제권코드 | | `10` 같은 2자리 문자열(명세 타입은 number) |
| statCdCntnKor1 | 경제권명 | | `EU` |
| expCnt | 수출건수 | 건 | 정수 |
| expDlr | 수출금액 | 달러 | 정수 |
| impCnt | 수입건수 | 건 | 정수 |
| impDlr | 수입금액 | 달러 | 정수 |
| balPayments | 무역수지 | 달러 | 정수, 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/economytrade/getEconomytradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606
```

## 함정

- **인자명 `cntnEbkUnfcClsfCd` 를 [대륙별](대륙별.md)과 같이 쓰지만 코드표가 다르다.** `10` 이 여기서는 `EU`, 대륙별에서는 `아시아` 다([코드표 함정](README.md#코드표-함정)).
- **응답에는 코드표에 없는 경제권이 있다.** 코드 생략 시 14개가 오는데, 코드표(13개)에 없는 `11` `EU28` 이 섞여 있다. 코드표만 보고 경제권 목록을 고정하지 말 것.
- **경제권은 서로 겹친다**(EU ⊂ OECD 등). 행을 더하면 전체 실적이 아니다. 2026.01 14개 경제권 `expDlr` 합은 177,583,646,094 로, 전 국가 합 65,843,636,561 의 약 2.7배다.
- `10` 을 주면 EU 6행.
