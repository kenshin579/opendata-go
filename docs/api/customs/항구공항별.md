# 항구공항별 수출입실적 (getPorttradeList)

> `GET https://apis.data.go.kr/1220000/porttrade/getPorttradeList`

선적·하역 항구·공항(지역)별로 월별 수출입 건수·금액·무역수지를 조회한다. 한 항구가 신고 세관별로 여러 행으로 나뉘어 온다. 포털: [15101636](https://www.data.go.kr/data/15101636/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| portAirptRegnCd | 항구공항지역코드 | - | N | `KRPUS`(부산항), `ICN`(인천국제공항), `010`(서울세관) 등. 코드는 [codes/항구공항코드.csv](codes/항구공항코드.csv). 생략하면 전 항구 |

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | **`202601` 형식**(점 없음). 총계 행은 `총계` |
| portCd | 항구공항지역코드 | | 문자열. 5자리 항만코드(`KRPUS`), 3자리 공항코드(`ICN`), 3자리 세관코드(`010`), `ZZZZZ`(기타항). 총계 행은 `-` |
| statKor | 항구공항지역명 | | `부산항`, `인천국제공항`, `서울세관`. 총계 행은 `-` |
| cstmSgn | 세관코드 | | 신고 세관 3자리 문자열(`010`). **총계 행에는 태그가 없다** |

## 샘플

## 함정

- **한 항구가 신고 세관(`cstmSgn`)별로 여러 행이다.** 2026.01 `KRPUS` 는 45행, `ICN` 은 44행. 항구별 합계가 필요하면 같은 `year`·`portCd` 끼리 더한다.
- **`portCd` 형식이 섞여 있다.** 항만은 UN/LOCODE 5자리(`KRPUS`), 공항은 3자리(`ICN`, `GMP`), 일부는 세관코드(`010` 서울세관, `037`, `040`), 기타는 `ZZZZZ`. 모두 문자열로 다룬다.
- **코드표의 세관 코드는 앞자리 0 이 빠져 있다.** `항구공항코드.csv` 는 `10,서울세관`·`37`·`40`·`13` 이지만 응답과 실측 인자는 `010` 이다(`portAirptRegnCd=010` → 28행 + 총계). `10` 으로 조회되는지는 미실측. [코드표 함정](README.md#코드표-함정)
- **마지막 행이 총계이고 `cstmSgn` 태그가 없다.** `year` 가 `총계` 인 행으로 판별한다([총계 행](README.md#총계-행)).
- **총계가 다른 API 와 조금 다르다.** 6개월 수출 496,114,604,700달러·6,808,212건으로, [종류별](종류별.md)·[세관별](세관별.md)의 496,114,738,264달러·6,808,222건보다 133,564달러·10건 작다. 원인은 모른다.
- 응답이 크다(6개월 685KB). 필요한 항구만 `portAirptRegnCd` 로 좁힌다.
- **기간이 `202601` 형식이다**([응답 필드 계열](README.md#응답-필드-계열)).
