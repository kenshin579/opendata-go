# 국가별 수출입실적 (getNationtradeList)

> `GET https://apis.data.go.kr/1220000/nationtrade/getNationtradeList`

국가별 월별 수출입 건수·금액·무역수지를 조회한다(품목 구분 없음). 포털: [15101612](https://www.data.go.kr/data/15101612/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| cntyCd | 국가코드 | - | N | 대문자 2자리(`US`). 생략하면 전 국가. 코드는 [codes/국가코드.csv](codes/국가코드.csv) |

## 응답 필드 (`response/body/items/item`)

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | `2026.01` 형식 |
| statCd | 국가코드 | | `US` |
| statCdCntnKor1 | 국가명 | | `미국` |
| expCnt | 수출건수 | 건 | 정수 |
| expDlr | 수출금액 | 달러 | 정수 |
| impCnt | 수입건수 | 건 | 정수 |
| impDlr | 수입금액 | 달러 | 정수 |
| balPayments | 무역수지 | 달러 | 정수, 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/nationtrade/getNationtradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&cntyCd=US
```

6행(월별 1행). 총계 행은 없다.

```xml
<item><balPayments>5244595000</balPayments><expCnt>196748</expCnt><expDlr>12006733027</expDlr><impCnt>1433422</impCnt><impDlr>6762138027</impDlr><statCd>US</statCd><statCdCntnKor1>미국</statCdCntnKor1><year>2026.01</year></item>
<item><balPayments>6944252301</balPayments><expCnt>182305</expCnt><expDlr>12704240943</expDlr><impCnt>1313995</impCnt><impDlr>5759988642</impDlr><statCd>US</statCd><statCdCntnKor1>미국</statCdCntnKor1><year>2026.02</year></item>
```

## 함정

- `cntyCd` 를 생략하면 전 국가가 온다(6개월 1,412행, 2026.01 은 237개국). 그 달 실적이 없는 국가는 행이 빠지므로 월마다 국가 수가 다르다. 총계 행은 없다.
- 국가코드는 대문자만 받는다. `us`·`QQ` 는 99 `존재하지 않는 국가코드입니다.`(body 없음).
- 필수 인자 누락 등 에러 응답에 `body` 태그가 없다([에러](../README.md#b-기관-서비스-에러)).
