# 신성질별 국가별 수출입실적 (getNnewtempertradeList)

> `GET https://apis.data.go.kr/1220000/nnewtempertrade/getNnewtempertradeList`

관세청 **신성질별 분류**(수출·수입 공통 8자리)로 한 국가의 월별 수출 또는 수입 중량·금액을 조회한다. [신성질별](신성질별.md)에 국가 조건을 더한 것이고, [성질별국가별](성질별국가별.md)의 현행 분류(5자리)와는 다른 코드 체계다. 포털: [15101607](https://www.data.go.kr/data/15101607/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| imexTpcd | 수출입구분코드 | - | Y | `1` 수출, `2` 수입([codes/수출수입코드.csv](codes/수출수입코드.csv)) |
| imexTmprUnfcClsfCd | 수출입성질통합분류코드 | - | 명세 Y / 실측 생략 가능 | **8자리 세세분류코드**(`13050102`) — [codes/성질통합분류코드.csv](codes/성질통합분류코드.csv) 15번째 열. 생략하면 그 국가의 전 성질 |
| cntyCd | 국가코드 | - | Y | 대문자 2자리(`US`). 생략하면 99. 코드는 [codes/국가코드.csv](codes/국가코드.csv) |

## 샘플

```
GET https://apis.data.go.kr/1220000/nnewtempertrade/getNnewtempertradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&imexTpcd=1&imexTmprUnfcClsfCd=13050102&cntyCd=US
```

6행(월별 1행). 총계 행은 없다.

## 함정

- **성질통합분류코드는 8자리 세세분류만 매칭된다.** 상위로 묶어 주지 않는다. 미국 수출 6개월 실측:

  | `imexTmprUnfcClsfCd` | 코드표 열 | 결과 |
  | --- | --- | --- |
  | `13050102` (기초화장품) | 15 세세분류 | 6행 |
  | `13050100` | 13 세분류 | 0건 |
  | `13050000` | 11 소분류 | 0건 |
  | `11000000` / `10000000` | 9 중분류 / 7 대분류 | 0건 |
  | `1` | | 0건 |

  0건은 에러가 아니라 `resultCode` 00 + `<items/>` 라서 잘못된 코드를 넣어도 알아채기 어렵다.
- **실적이 드문 코드는 0건처럼 보인다.** `11020101`(말)은 2026.01~04 실적이 없어 05·06 두 행만 온다. 코드가 틀린 게 아닐 수 있으니 기간을 넓혀 확인한다.
- **`imexTmprUnfcClsfCd` 는 생략할 수 있다.** 명세는 필수지만 빼면 그 국가의 전 세세분류가 온다(미국 수출 6개월 3,019행·573개 코드).
- **`cntyCd` 는 실제로 필수다.** 빼면 99 `필수 요청변수가 누락되었습니다.`(`<body/>`). 국가 구분 없이 보려면 [신성질별](신성질별.md).
- `imexTpcd=2`(수입)·`cntyCd=CN` 도 같은 필드로 6행이 온다.
