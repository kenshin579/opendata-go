# 시군구별 수출입실적 (getSigunguPerImexAcrs)

> `GET https://apis.data.go.kr/1220000/sigunguperimexacrs/getSigunguPerImexAcrs`

한 시도에 속한 시군구별로 **월별** 수출입 건수·금액·무역수지를 조회한다. 지역은 수출은 제조장소, 수입은 납세의무자 주소지 우편번호 기준이다(포털 명세). 포털: [15134344](https://www.data.go.kr/data/15134344/openapi.do)

API 13~17 은 API 1~12 와 응답 필드 이름·숫자 형식·금액 단위가 다르다. 대응 관계는 [관세청 README 응답 필드 계열](README.md#응답-필드-계열)을 본다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| sidoCd | 시도코드 | - | Y | 2자리(`41` 경기도). 코드는 [codes/시도코드.csv](codes/시도코드.csv) — 광주·전남은 2026.7.1. 전후로 코드가 다르다([코드표 함정](README.md#코드표-함정)). 생략하면 99 |

## 응답 필드 (`response/body/items/item`)

숫자 필드는 모두 **공백 패딩 + 천 단위 콤마 문자열**(`          -2,218`, 16자 고정폭)이다. item 밖 `response/body/totalCount` 에 item 개수가 온다(아래 함정).

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| priodTitle | 기간 | | **`2026.01` 형식(월별)**. 시도 계열(13~15)과 다르다 |
| sidoSggNm | 시군구명 | | 시도명 포함(`경기도 가평군`) |
| expCnt | 수출건수 | 건 | |
| expUsdAmt | 수출금액 | 천 달러 | 명세는 "수출미화금액"(단위 없음) |
| impCnt | 수입건수 | 건 | |
| impUsdAmt | 수입금액 | 천 달러 | |
| cmtrBlncAmt | 무역수지 | 천 달러 | 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/sigunguperimexacrs/getSigunguPerImexAcrs?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&sidoCd=41
```

186행(6개월 × 경기도 시군 31개), `totalCount` 186. 총계 행은 없다.


## 함정

- **`totalCount` 가 있지만 페이지네이션은 없다.** 값은 item 개수와 같고, `numOfRows`·`pageNo` 를 넣어도 같은 186행이 온다([공통 규약](../README.md#공통-인자)).
- **금액이 천 달러다.** 경기도 시군 6개월 `expUsdAmt` 합 159,023,487 이 [시도별](시도별.md) 경기도 159,022,310 과 맞는다(반올림 차).
- **월별이다.** 같은 계열의 [시도별](시도별.md)은 연 단위 합산(`2026`)이지만 이 API 는 `2026.01` 처럼 월마다 행이 온다. 총계 행도 없다.
- **구 행정명이 남아 있다.** `경기도 포천군`(2003 시 승격), `경기도 여주군`(2013 시 승격)으로 온다. 시·구 단위로 쪼개지 않고 `경기도 수원시`·`경기도 고양시` 처럼 시 단위다.
- **숫자가 문자열이다.** 공백과 콤마를 지운 뒤 정수로 바꾼다.
- `sidoCd` 누락은 99 `필수 요청변수가 누락되었습니다.` 이고 body 가 `<body><totalCount>0</totalCount></body>` 로 온다([에러](../README.md#b-기관-서비스-에러)).
- 명세는 2026.7.1. 행정체계 개편 이후 시군구 코드가 바뀌었다고 적었다. 응답에 시군구 코드는 없고 이름만 온다. 개편 전후를 걸친 조회는 미실측.
