# 품목별 국가별 수출입실적 (getNitemtradeList)

> `GET https://apis.data.go.kr/1220000/nitemtrade/getNitemtradeList`

HS 품목코드와 국가를 조건으로 월별 수출입 중량·금액·무역수지를 조회한다. 포털: [15100475](https://www.data.go.kr/data/15100475/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | 100 | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | 6 | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | 6 | Y | `YYYYMM` |
| hsSgn | 품목코드 | 10 | N | HS 2·4·6·10자리. 그 밖의 자릿수는 99 에러. 자릿수가 출력 행 단위를 정한다(함정). 코드는 [codes/품목코드.csv](codes/품목코드.csv) |
| cntyCd | 국가코드 | 2 | 명세 Y / 실측 생략 가능 | 대문자 2자리(`CN`). 생략하면 전 국가. 코드는 [codes/국가코드.csv](codes/국가코드.csv) |

## 샘플

```
GET https://apis.data.go.kr/1220000/nitemtrade/getNitemtradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&hsSgn=8542&cntyCd=CN
```

31행(총계 1 + 6개월 × HS 6자리 5개). 첫 행이 총계다.

## 함정

- **`cntyCd` 는 생략할 수 있다.** 명세는 필수라 하지만, 빼면 전 국가 행이 온다(`hsSgn=8542`, 6개월 1,371행).
- **`hsSgn` 자릿수가 출력 행 단위를 바꾼다.** 2자리 → 4자리 행(`85` → 289행), 4자리 → 6자리 행(`8542` → `854231`~`854290`), 6자리·10자리 → 10자리 행, 생략 → 10자리 행(전 품목, 국가 `CN` 6개월 47,439행·13MB). 3·5·8자리 등은 99 `품목코드는 2,4,6,10 자리로 입력해야 합니다.`(`<body/>`).
- 같은 뜻의 HS코드 필드가 [품목별](품목별.md)에서는 `hsCode` 다. 이 API 는 `hsCd`.
- **첫 행이 총계다.** `year` 가 `총계` 인 행을 걸러야 한다([총계 행](README.md#총계-행)).
- 코드(`hsCd`)는 `0101` 처럼 0 으로 시작할 수 있으니 문자열로 다룬다.
