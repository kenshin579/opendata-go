# 시도별 수출입실적 (getSidotradeList)

> `GET https://apis.data.go.kr/1220000/sidotrade/getSidotradeList`

시도(광역자치단체)별 수출입 건수·금액·무역수지를 **연 단위 합산**으로 조회한다. 포털: [15101643](https://www.data.go.kr/data/15101643/openapi.do)

API 13~17 은 API 1~12 와 응답 필드 이름·숫자 형식·금액 단위가 다르다. 대응 관계는 [관세청 README 응답 필드 계열](README.md#응답-필드-계열)을 본다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| sidoCd | 시도코드 | - | N | 2자리(`41` 경기도). 코드는 [codes/시도코드.csv](codes/시도코드.csv) — 광주·전남은 2026.7.1. 전후로 코드가 다르다([코드표 함정](README.md#코드표-함정)). 생략하면 전 시도 |

## 응답 필드 (`response/body/items/item`)

숫자 필드는 모두 **공백 패딩 + 천 단위 콤마 문자열**(`     137,311,058`, 16자 고정폭)이다.

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| priodTitle | 기간 | | **연도 `2026`**(월이 아님). 총계 행은 `총계` |
| sidoNm | 시도명 | | `서울특별시`. **총계 행에는 태그가 없다** |
| expCnt | 수출건수 | 건 | |
| expUsdAmt | 수출금액 | 천 달러 | 명세는 "달러" |
| impCnt | 수입건수 | 건 | |
| impUsdAmt | 수입금액 | 천 달러 | 명세는 "달러" |
| cmtrBlncAmt | 무역수지 | 천 달러 | 음수 가능(`     -68,733,092`) |

## 샘플

```
GET https://apis.data.go.kr/1220000/sidotrade/getSidotradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606
```

18행(총계 + 시도 17개). 첫 행이 총계다.

## 함정

- **월별이 아니라 연 단위 합산이다.** 6개월을 조회해도 시도마다 `2026` 한 행이고, 한 달만 조회해도 `2026` 이다. 연도를 걸치면 연도별로 나뉜다(`202507~202606` → `2025` 17행 + `2026` 17행 + 총계 = 35행). 월별 값이 필요하면 한 달씩 따로 부른다.
- **금액이 천 달러다.** 명세는 "달러"지만 총계 `expUsdAmt` 496,113,564 가 [종류별](종류별.md) 총계 496,114,738,264달러와 같은 규모라 천 달러로만 말이 된다. 다만 값은 1,174 천 달러 작아 반올림 차가 아니다. API 사이 총계는 조금씩 다르니(집계 기준 차이로 보임, 원인 미확인) 같다고 가정하지 않는다([응답 필드 계열](README.md#응답-필드-계열)).
- **숫자가 문자열이다.** 공백과 콤마를 지운 뒤 정수로 바꾼다.
- **첫 행이 총계이고 `sidoNm` 태그가 없다.** `priodTitle` 이 `총계` 인 행으로 판별한다([총계 행](README.md#총계-행)). `sidoCd=41` 처럼 한 시도만 골라도 총계 + 경기도 2행이 오고 두 행 값이 같다.
- 2026.01~06 조회에는 `12` 전남광주통합특별시 행이 없고 `광주광역시`·`전라남도` 가 따로 나온다.
