# 대륙별 수출입실적 (getContinenttradeList)

> `GET https://apis.data.go.kr/1220000/continenttradet/getContinenttradeList`

대륙별 월별 수출입 건수·금액·무역수지를 조회한다. 포털: [15101630](https://www.data.go.kr/data/15101630/openapi.do)

서비스 경로 `continenttradet` 의 끝 `t` 는 오타처럼 보이지만 명세 원문 그대로이고, 이 경로로 호출해 정상 응답을 받았다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| cntnEbkUnfcClsfCd | 대륙경제권통합분류코드 | - | N | 대륙코드 2자리(`10` 아시아). 생략하면 전 대륙. 코드는 [codes/대륙코드.csv](codes/대륙코드.csv) |

## 응답 필드 (`response/body/items/item`)

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | `2026.01` 형식 |
| statCd | 대륙코드 | | `10` 같은 2자리 문자열. 명세는 "국가부호코드"(number)라고 적었지만 실제 값은 대륙코드다 |
| statCdCntnKor1 | 대륙명 | | `아시아`. 명세 명칭은 "국가부호명" |
| expCnt | 수출건수 | 건 | 정수 |
| expDlr | 수출금액 | 달러 | 정수 |
| impCnt | 수입건수 | 건 | 정수 |
| impDlr | 수입금액 | 달러 | 정수 |
| balPayments | 무역수지 | 달러 | 정수, 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/continenttradet/getContinenttradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606
```

## 함정

- **인자명 `cntnEbkUnfcClsfCd` 를 [경제권별](경제권별.md)과 같이 쓰지만 코드표가 다르다.** `10` 이 여기서는 `아시아`, 경제권별에서는 `EU` 다([코드표 함정](README.md#코드표-함정)).
- 코드를 생략하면 코드표의 9개 대륙(`99` 기타 포함)이 전부 온다. `10` 을 주면 아시아 6행.
- 대륙은 겹치지 않는다. 2026.01 대륙 9개의 `expDlr` 합 65,843,567,836 은 [국가별](국가별.md) 전 국가 합 65,843,636,561 과 거의 같다(차이 0.0001%). 반면 경제권은 겹친다.
- `statCd`·`statCdCntnKor1` 은 [국가별](국가별.md)과 이름이 같지만 대륙을 뜻한다.
