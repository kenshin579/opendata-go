# 종류별 수출입실적 (getKindtradeList)

> `GET https://apis.data.go.kr/1220000/kindtrade/getKindtradeList`

수출입 거래 종류(일반수출, 보세공장으로부터 수출 등)별로 월별 수출 또는 수입 건수·중량·금액을 조회한다. 원화 금액(`won`)을 함께 주는 유일한 API 다. 포털: [15101634](https://www.data.go.kr/data/15101634/openapi.do)

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| imexKcd | 수출입종류코드 | - | N | 수출은 영문(`A` 일반수출), 수입은 숫자(`11` 일반수입(외화획득용)). 코드는 [codes/수출입종류코드.csv](codes/수출입종류코드.csv) — 수출·수입 표가 좌우로 나뉜다. 명세 타입은 number 지만 영문이다. 생략하면 전 종류 |
| imexTpcd | 수출입구분코드 | - | Y | `1` 수출, `2` 수입([codes/수출수입코드.csv](codes/수출수입코드.csv)) |

| impexp | 수출입구분 | | `수출` 또는 `수입` |

## 샘플

```
GET https://apis.data.go.kr/1220000/kindtrade/getKindtradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&imexTpcd=1
```

49행(6개월 × 수출 종류 8개 + 총계). 마지막 행이 총계다.

## 함정

- **`won`(원화 금액)은 이 API 에만 있다.** 다른 16개 API 는 달러뿐이다. 값이 커서(총계 735,572,977,846,960원) 32비트 정수에 안 들어간다.
- **기간이 `202601` 형식이다.** API 1~9 의 `2026.01` 과 다르다([응답 필드 계열](README.md#응답-필드-계열)).
- **`statCd` 는 종류코드다.** 이름은 다른 API 의 국가코드 필드와 같지만 값은 `A`·`B` 같은 수출입종류코드다.
- **마지막 행이 총계다.** `year` 가 `총계` 인 행을 걸러야 한다([총계 행](README.md#총계-행)). `imexKcd=A` 로 좁혀도 6행 + 총계 1행이 온다.
- 수출 종류는 응답에 8개(`A B D E F H L P`)만 나온다. 코드표의 수출 10개 중 실적 없는 종류는 행이 빠진다.
- 수입(`imexTpcd=2`)은 실측하지 않았다.
