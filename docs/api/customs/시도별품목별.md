# 시도별 품목별 수출입실적 (getSidoitemtradeList)

> `GET https://apis.data.go.kr/1220000/sidoitemtrade/getSidoitemtradeList`

한 시도의 HS 2자리(류)별 수출입 란수·금액·무역수지를 **연 단위 합산**으로 조회한다. 포털: [15101641](https://www.data.go.kr/data/15101641/openapi.do)

API 13~17 은 API 1~12 와 응답 필드 이름·숫자 형식·금액 단위가 다르다. 대응 관계는 [관세청 README 응답 필드 계열](README.md#응답-필드-계열)을 본다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| sidoCd | 시도코드 | - | Y | 2자리(`41` 경기도). 코드는 [codes/시도코드.csv](codes/시도코드.csv) — 광주·전남은 2026.7.1. 전후로 코드가 다르다([코드표 함정](README.md#코드표-함정)) |

품목 코드로 거르는 인자는 없다. 항상 96개 류 전체가 온다.

## 응답 필드 (`response/body/items/item`)

숫자 필드는 모두 **공백 패딩 + 천 단위 콤마 문자열**(`          57,494,516`, 20자 고정폭)이다.

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| priodTitle | 기간 | | **연도 `2026`**(월이 아님). 총계 행은 `총계`. 명세 타입은 number |
| hsSgn | 품목코드 | | HS 2자리 문자열(`01`). **총계 행에는 태그가 없다** |
| korePrlstNm | 품목명 | | 류 명칭(`살아 있는 동물`). **총계 행에는 태그가 없다** |
| expLnCnt | 수출 란수 | 건 | 명세는 "수출품목건수". API 13 의 `expCnt`(신고 건수)와 값이 다르다 |
| expUsdAmt | 수출금액 | 천 달러 | 명세는 "달러" |
| impLnCnt | 수입 란수 | 건 | 명세는 "수입품목건수" |
| impUsdAmt | 수입금액 | 천 달러 | 명세는 "달러" |
| cmtrBlncAmt | 무역수지 | 천 달러 | 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/sidoitemtrade/getSidoitemtradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&sidoCd=41
```

## 함정

- **연 단위 합산이다.** 연도를 걸치면 연도별로 나뉜다(`202507~202606` → 193행 = 2025 96 + 2026 96 + 총계). [시도별](시도별.md#함정)과 같다.
- **건수 필드가 `expCnt` 가 아니라 `expLnCnt`·`impLnCnt` 이고 값도 다르다.** 경기도 2026.01~06 수출: 이 API 총계 2,354,891, [시도별](시도별.md) `expCnt` 1,521,862. 신고 한 건에 란(품목)이 여럿이라 란 수로 보인다(추정). 금액은 두 API 가 같다(159,022,310).
- **금액이 천 달러다.** 총계 `expUsdAmt` 가 [시도별](시도별.md) 경기도 값과 같다.
- **첫 행이 총계이고 `hsSgn`·`korePrlstNm` 태그가 없다**([총계 행](README.md#총계-행)).
- **`hsSgn` 은 0 으로 시작한다**(`01`). 문자열로 다룬다.
- `korePrlstNm` 은 코드표 품목명이 아니라 긴 류 명칭이다([코드표 함정](README.md#코드표-함정)).
- 숫자 문자열 폭이 20자로 API 13·15·16·17(16자)과 다르다. 폭에 기대지 말고 공백을 지운다.
