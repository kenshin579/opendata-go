# 시군구별 품목별 수출입실적 (getSigunguPerPrlstPerAcrs)

> `GET https://apis.data.go.kr/1220000/sigunguperprlstperacrs/getSigunguPerPrlstPerAcrs`

한 시도에 속한 시군구별로 HS 6단위 품목 하나의 **월별** 수출입 건수·금액·무역수지를 조회한다. 지역은 수출은 제조장소, 수입은 납세의무자 주소지 우편번호 기준이다(포털 명세). 포털: [15134343](https://www.data.go.kr/data/15134343/openapi.do)

API 13~17 은 API 1~12 와 응답 필드 이름·숫자 형식·금액 단위가 다르다. 대응 관계는 [관세청 README 응답 필드 계열](README.md#응답-필드-계열)을 본다.

## 응답 필드 (`response/body/items/item`)

숫자 필드는 모두 **공백 패딩 + 천 단위 콤마 문자열**(`           9,658`, 16자 고정폭)이다. item 밖 `response/body/totalCount` 에 item 개수가 온다([시군구별](시군구별.md#함정)과 같음).

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| priodTitle | 기간 | | **`2026.01` 형식(월별)** |
| sggNm | 시군구명 | | 시도명 포함(`경기도 고양시`). [시군구별](시군구별.md)은 같은 값이 `sidoSggNm` 이다 |
| hsSgn | HS부호 | | 요청한 6자리 그대로(`854232`). 소문자 `h` |
| korePrlstNm | 품목명 | | `메모리` |
| expCnt | 수출건수 | 건 | |
| expUsdAmt | 수출금액 | 천 달러 | 명세는 "수출미화금액"(단위 없음) |
| impCnt | 수입건수 | 건 | |
| impUsdAmt | 수입금액 | 천 달러 | |
| cmtrBlncAmt | 무역수지 | 천 달러 | 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/sigunguperprlstperacrs/getSigunguPerPrlstPerAcrs?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&sidoCd=41&HsSgn=854232
```

## 함정

- **요청 인자는 대문자 `HsSgn`, 응답 필드는 소문자 `hsSgn` 이다.** 요청에 소문자 `hsSgn` 을 넣어도 대문자와 같은 item 22개가 왔다(2026.01 경기도 854232 대조). 클라이언트는 명세대로 `HsSgn` 을 쓴다.
- **시군구명 필드가 `sggNm` 이다.** [시군구별](시군구별.md)은 `sidoSggNm`.
- **시군구 단위 반도체 수출을 볼 수 있는 유일한 API 다.** 경기도 854232(메모리) 6개월 수출은 평택 27,144,517 · 이천 16,415,581 · 용인 11,609,105 · 수원 6,083,429(천 달러) 순이다. 2단계에서 moneyflow 가 쓸 곳이다.
- **금액은 천 달러로 본다.** 경기도 시군 6개월 수출 합 61,490,109 는 전국 854232 수출 123,503,381,846달러([품목별](품목별.md))의 약 절반이다. 달러로 읽으면 0.05% 라 맞지 않는다. 직접 대조할 시도 단위 품목 값은 없다.
- **실적이 없는 시군은 행이 빠진다.** 월마다 행 수가 다르다(22~24).
- `totalCount` 는 item 개수일 뿐 페이지네이션은 없다.
- **숫자가 문자열이다.** 공백과 콤마를 지운 뒤 정수로 바꾼다.
