# 품목별 수출입실적 (getItemtradeList)

> `GET https://apis.data.go.kr/1220000/Itemtrade/getItemtradeList`

HS 품목코드별 월별 수출입 중량·금액·무역수지를 조회한다(국가 구분 없음). 포털: [15101609](https://www.data.go.kr/data/15101609/openapi.do)

서비스 경로는 대문자 `I` 로 시작하는 `Itemtrade` 다.

## 기본 정보

| 메서드 | 출력포맷 | 갱신 | 트래픽(개발) |
| --- | --- | --- | --- |
| GET | XML (JSON 불가, [공통 규약](../README.md#공통-인자)) | 매월 15일경 전월까지 | 10,000/일 |

## 요청 인자

Swagger 명세에는 크기가 없다.

| 인자 | 명칭 | 크기 | 필수 | 값 설명 |
| --- | --- | --- | --- | --- |
| serviceKey | 서비스키 | - | Y | [공통 규약](../README.md#서비스키) |
| strtYymm | 시작년월 | - | Y | `YYYYMM`. 종료년월까지 최대 12개월 |
| endYymm | 종료년월 | - | Y | `YYYYMM` |
| hsSgn | 품목코드 | - | N | HS 코드 앞자리(2·4·6·10자리 실측). 출력은 항상 10자리 행. 명세 타입은 number 지만 `0101` 처럼 0 으로 시작하므로 문자열로 보낸다. 코드는 [codes/품목코드.csv](codes/품목코드.csv) |

## 응답 필드 (`response/body/items/item`)

| 필드 | 명칭 | 단위 | 설명 |
| --- | --- | --- | --- |
| year | 기간 | | `2026.01` 형식. 총계 행은 `총계` |
| hsCode | HS코드 | | 10자리 문자열(명세 타입은 number). 총계 행은 `-` |
| statKor | 품목명 | | 10자리 품목명. 총계 행은 `-` |
| expWgt | 수출중량 | kg | 정수 |
| expDlr | 수출금액 | 달러 | 정수 |
| impWgt | 수입중량 | kg | 정수 |
| impDlr | 수입금액 | 달러 | 정수 |
| balPayments | 무역수지 | 달러 | 정수, 음수 가능 |

## 샘플

```
GET https://apis.data.go.kr/1220000/Itemtrade/getItemtradeList?serviceKey={SERVICE_KEY}&strtYymm=202601&endYymm=202606&hsSgn=8542
```

## 함정

- **HS코드 필드 이름이 `hsCode` 다.** [품목별국가별](품목별국가별.md)은 같은 뜻의 필드가 `hsCd` 다.
- **입력 자릿수와 관계없이 항상 10자리 행이 온다.** [품목별국가별](품목별국가별.md)처럼 한 단계 아래로 묶어 주지 않는다. `85` → 4,264행(6개월), `854232` → 43행. 류·호 단위 합계가 필요하면 직접 더한다.
- 10자리 코드가 코드표에 없으면 에러가 아니라 0건(`<items/>`)이다(`8542321000`).
- **마지막 행이 총계다.** `year` 가 `총계` 인 행을 걸러야 한다([총계 행](README.md#총계-행)).
